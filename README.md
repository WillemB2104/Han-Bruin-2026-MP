# Bruin-2026-MP

Code accompanying the following publication:

> Han, L. K. M.*, Bruin, W. B.*, et al. (2026). **Structural brain differences associated with panic disorder: an ENIGMA-Anxiety Working Group mega-analysis of 4,924 individuals worldwide.** *Molecular Psychiatry*, 31(5), 2402–2417. https://doi.org/10.1038/s41380-025-03376-4

\* Shared first authorship.

## Overview

This repository contains the analysis scripts used for the ENIGMA-Anxiety Panic Disorder Working Group mega-analysis. The scripts implement the batch processing of linear mixed-effects models for large-scale multisite neuroimaging analyses, including statistical analyses, quality control, and generation of the reported results.

The analysis framework was adapted from the ENIGMA-Parkinson's Disease Working Group pipeline developed by Max Laansma and the ENIGMA Disease Working Group statistical scripts.

## Repository contents

- Data preparation and quality control
- Batch linear mixed-effects modeling
- Statistical analyses
- Generation of summary statistics, tables, and figures

## Data availability

The individual-level data analyzed in this study belong to the ENIGMA-Anxiety Consortium and are subject to local ethics approvals and institutional data-sharing agreements. Consequently, the data cannot be distributed through this repository.
